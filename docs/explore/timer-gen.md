# 通用、基本与低功耗定时器

## Cortex-M0/M0+

TIM0–3 的 MODE0、MODE1、MODE23 是同址视图。同一实例在设备数据中保留模式关系。

| 建议版本 | 系列或实例 | 布局备注 |
|---|---|---|
| `timer3_v1_m0` | A136 F030 F072 F17x F19x L07x L12x L13x L16x L17x L18x L19x 的 TIM0–3 | MODE0 全同（48/48 同 hash） |
| `timer3_v1_m1` | A136/F030/F072/F17x/F19x/L07x/L13x/L17x/L19x | CR0 无 CSA/CSB |
| `timer3_v1l_m1` | L12x/L16x/L18x | CR0 增 CSA/CSB |
| `timer3_v1_m23` | A136/F030/L13x 的 TIM0-2 | DTR 有 VC0E/VC1E |
| `timer3_v1_m23b` | F072/F17x/F19x/L07x/L17x/L19x 的 TIM0-2 | DTR 合并 VCE |
| `timer3_v1_m23c` | L12x/L16x/L18x 的 TIM0-2 | m23b + OVF/UNDF 中断 |
| `timer3_v1_m23_3ch / _3chb / _3chc / _3chd` | TIM3（A136/F030/L13x；F072/F17x/F19x/L07x/L17x/L19x；L16x/L18x；L12x） | TIM3 = 三通道型，簇边界与 TIM0-2 一致 |
| `timer3_v1_basic` | F003/F005 TIM0-2；L110 BT0-2 | 6 寄存器基本型（driver `bt`） |
| `gtim_v1a / gtim_v1b / gtim_v1c` | A052/F052；L021；F002 | 差异仅 IER 位数 |
| `btim_v1 / btim_v2` | A052/F052 BTIM0-2、L021 BTIM0-5；A052/F052 BTIM3-5、F002 BTIM3-5 | 仅 AICR/AIFR 字段命名（可酌情合并为 1 版 + 注释） |
| `lptim_v1`–`lptim_v4` | v1: A136/L13x/L110，v2: A052/F052，v3: L07x/L16x/L17x/L18x/L19x，v4: L12x | LPTIM/LPTIMER 命名随系列变化。 |

## HC32F420（Cortex-M4）

CTIM0–2 各有一组 GTIM/BTIM 复用视图，由 SYSCTRL 选择。GTIM 沿用
`gtim_v1a`，`IER.CH0TRAD` 是 A052/F052 的 `IER.C0TRAD`（bit 11）。
BTIM0–8 共享寄存器骨架，AIFR/AICR 按 bank 使用 `UI0/TI0` 至 `UI8/TI8`。
其中 BTIM3–5 与 A052/F052/F002 对应实例的位域命名一致。

| F420 物理块 | 复用视图 | 共享 IRQ | APB0EN 位 | GTIM DMA 请求 |
|---|---|---|---:|---|
| CTIM0 | GTIM0、BTIM0–2 | 34–36 | 20 | `0x48` |
| CTIM1 | GTIM1、BTIM3–5 | 37–39 | 21 | `0x49` |
| CTIM2 | GTIM2、BTIM6–8 | 40–42 | 22 | `0x4A` |

IRQ 后缀依次为 `UEV_ETR_BTIMA`、`CH01_BTIMB`、`CH23_BTIMC`。
`driver/inc/sysctrl.h` 的 `Sysctrl_Fun_Gtim*_0_Btim*_1` 枚举选择 GTIM/BTIM。
`driver/inc/dmac.h` 只为 GTIM 视图列出 DMA 请求。
